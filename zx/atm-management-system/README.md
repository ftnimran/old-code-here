# 🏧 ATM Management System

This is an **ATM Management System** built using **React.js, Vite, and CSS**. It simulates basic ATM operations like **login, balance inquiry, cash withdrawal, deposit, PIN change, and transaction history** with a clean and responsive interface.

---

## 📌 Features

- 🔐 PIN Authentication
- 💰 Balance Inquiry
- 💵 Cash Withdrawal
- 💳 Deposit Money
- 🔑 Change PIN
- 📄 Transaction History
- 📱 Responsive UI
- ⚡ Fast performance with Vite

---

## 🛠️ Built With

- React.js
- Vite
- JavaScript (ES6+)
- CSS3
- React Context API

## ⚙️ Installation & Setup

Clone the repository

```bash
git clone https://github.com/your-username/atm-management-system.git
```

Go to the project directory

```bash
cd atm-management-system
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```
